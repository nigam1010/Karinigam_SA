## 🧠 What Makes Me Different

Most people pick a lane. I deliberately didn't.

As a **Product Manager**, I think in user problems, RICE scores, and north star metrics.
As a **Full-Stack Developer**, I can spec a feature *and* build it — no translation layer needed.
As a **Data Analyst**, I back decisions with pipelines, dashboards, and actual numbers.

> The intersection of these three is where I work best — shipping things that are *strategically sound, technically real, and data-informed.*
